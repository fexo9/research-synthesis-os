## The 15-minute research gate

**1. Define.** One sentence: the research question + scope boundaries.

**2. Grade every source:**

| Tier | Meaning |
| --- | --- |
| S1 | Primary: official stats, direct measurements, first-hand data |
| S2 | Reputable secondary that cites its own sources |
| S3 | Unverified: blogs without citations, forums, AI content |

Two articles quoting the same press release are ONE source, not two. The AI's
summary of a source is not the source.

**3. Extract claims.** One claim, one row. Material claims (numbers, dates, anything
the reader will act on) need S1 or 2+ independent S2s.

**4. Flag contradictions.** Sources disagree → record BOTH, mark CONTESTED, disclose
in the brief. Never silently resolve in favor of the convenient one.

**5. Run the quality gate.** PASS only when: every material claim has a logged source,
no unresolved contradiction, no S3-only claim presented as fact, and uncertainty is
disclosed. Otherwise: REVISE.

**6. Output:**

```
### RESEARCH QUESTION
question: / scope:

### CLAIM BANK
| Claim | Sources | Tier | State |

### BRIEF — [executive / compare / timeline / pros-cons-verdict]
answer + confidence level

### QUALITY GATE — PASS / REVISE
```

## Try it

Pick any claim you were about to publish and run the six steps. If the gate says
REVISE, you just caught what "looks right" would have shipped.
